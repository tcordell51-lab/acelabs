# Prometric mock build pipeline

Pipeline for regenerating `shared/dat-mock-tests.js`. Run scripts in order:

```sh
# 1. (Optional) re-extract banks from the 4 tools — only needed if a tool's bank changed.
#    The extracted unified bank lives at scripts/dat-mock-bank.json.

# 2. Annotate the OChem bank with SMILES strings for the molecules referenced in
#    each question. Conservative — only adds SMILES for unambiguous matches.
node scripts/annotate-smiles.js

# 3. (Optional) re-author the 8 hand-built ADA-spec arrow-prediction questions.
#    Already merged into scripts/dat-mock-bank.json — run only on a fresh bank.
node scripts/arrow-questions.js

# 4. Compose 5 ADA-aligned practice tests from the unified bank.
#    Enforces the official April 2026 OChem blueprint per test:
#      Mechanisms 7 · Chemical Synthesis 9 · Acid-Base 4 ·
#      Chemical & Physical Properties 6 · Structural Evaluation 4
node scripts/compose-tests.js

# 5. Export the composed tests to shared/dat-mock-tests.js (read by the runner)
node -e "
  const tests = require('./scripts/dat-mock-bank.json');  // not needed, just for path
  const t = require('/tmp/dat-mock-tests.json');
  const fs = require('fs');
  fs.writeFileSync('shared/dat-mock-tests.js',
    '// Generated by scripts/compose-tests.js\n' +
    'window.DAT_MOCK_TESTS = ' + JSON.stringify(t) + ';\n');
"
```

## Sources

- ADA *NEW Organic Chemistry Examination Specifications* (Aug 2025) — drives the 5-category OChem blueprint
- ADA *DAT 2026 Candidate Guide* (Dec 2025) — drives the 200-600 scoring scale, 30-min break, calculator UI, periodic table

## SMILES rendering

The runner loads `shared/smiles-drawer.min.js` (SmilesDrawer 2.1.7, MIT) and
calls `new SmiDrawer(opts).draw(smiles, canvas, 'light')` to render skeletal
structures inline next to question text and answer choices.

Bank entries that opt into rendering have one or more of:

- `q_smiles` — SMILES string for the molecule shown with the question
- `opts_smiles` — array of SMILES (or null) for each answer choice
- `q_svg` — inline SVG markup (used for the 8 hand-built arrow-prediction items)
- `opts_svg` — inline SVG markup per answer choice (rare)
- `_ada_category` — one of the 5 official OChem category labels
