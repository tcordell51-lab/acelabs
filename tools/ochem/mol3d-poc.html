Chirality you can turn over in your hand

A chiral carbon with four different groups. Drag to rotate. Flip it to its mirror image and watch the configuration switch — the two are non-superimposable. The R/S badge is computed from the actual 3D geometry, so it is always correct and flips with the mirror. (Pure CSS/SVG — no libraries, no network.)

Point the lowest priority (H, #4) away from you, then trace Br → Cl → F. Clockwise = R, counter‑clockwise = S. “Look down C–H” sets that exact view.
Self-contained: the molecule is rendered with plain JavaScript 3-D math, HTML gradient spheres, and an SVG bond layer — no three.js, no WebGL, no network, so it runs inside Ace Labs’ existing Content-Security-Policy with nothing to load. Geometry is procedural and the R/S label is derived from the coordinates. (A future production version could swap in WebGL once a vendored copy is served same-origin.)
