How this slots into the master HTML.
  • New storage key students_v1: {[id]: {name, testDate, attempts, mastery, stuck, threadKey}}. Existing attempts / mastery keys become the "active student" view; multi-student wraps them.
  • New storage key tutorThreads_v1: {[studentId]: [{t, who:'sarah'|'tommy', text}]}. Note thread is per-student, never per-skill (that's feature 2).
  • SARAH.toggle() already exists — extend it to also call renderSarahDash() with a Sarah-mode view that surfaces the picker. Today's dashboard still works for non-Sarah-mode visitors.
  • Weakest-3 selector: SKILLS.filter(unlocked).map(s => ({s, recent: attempts.filter(...)})).filter(r => r.recent.length >= 4).sort((a,b) => acc(a) - acc(b)).slice(0,3).
  • "Drop into module" button = existing goSec(skillId); Sarah-mode bar already follows.
