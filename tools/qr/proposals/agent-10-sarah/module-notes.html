Spec

How this slots in.
  • Storage key sarahModuleNotes_v1: {[skillId]: {text, t, by:'sarah'}}. Keyed by the existing 41 module IDs (frac-add, pct-chg, etc.).
  • Render hook: piggyback on the existing renderModule(skillId) wrapper at line 10390 of index.html. After tagEditables(skillId), insert the .sarah-note banner above the section's first .card if a note exists for that ID.
  • Only Sarah-mode can edit. The compose UI mounts when SARAH.on === true AND the user clicks "Edit note". Students see the banner read-only.
  • "Got it" acknowledgements record to sarahModuleAcks_v1 as {[skillId]: {[studentId]: ackedAtTimestamp}} so Sarah can confirm in her dashboard whether the student saw the note.
  • No rich text. Plain-text note plus light formatting via the existing em.gold / <b> classes in the master.
