Spec

How this slots into the master HTML.
  • STUCK.open() at line 9202 is augmented with one extra branch: "Flag this for review". It calls a new STUCK.flagAceCard() that reads the current module from SARAH.modules[SARAH.i] (or the most-recent renderModule argument) and the last attempt from ST.get('attempts',[]).
  • Storage key aceCards_v1 matches the bio tool's pattern: [{id, t, skill, problemId, stem, picked, correct, reflection, due, box}]. box tracks the Leitner level (0=24h, 1=3d, 2=7d, 3=14d, 4=mastered).
  • Sarah's dashboard surfaces all flagged cards with tag === 'stuck' as a high-priority section above the auto-generated plan.
  • When the card resurfaces (due ≤ now), it appears as a yellow-bordered subcard at the top of the module page. Get it right cold → bumps to next box. Miss → stays in box 0.
  • Reflection prompt is optional but encouraged. The free-text field doubles as a tutor hand-off — Sarah reads "I forgot to convert minutes to hours" and knows exactly what to coach.
