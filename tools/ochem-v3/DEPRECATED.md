# OChem v3 — DEPRECATED

**This directory is deprecated.** The production OChem coaching tool is **v1 (Reaction Maps)** at `../ochem/`.

## Why this exists

OChem v3 was an experimental "lesson-by-lesson study path" iteration explored in earlier development. After review, the team chose to standardize on **v1 (the Reaction Maps gamified hub-grid tool)** as the primary OChem coaching engine going forward.

See [../ochem/COACH_GUIDE_README.md](../ochem/COACH_GUIDE_README.md) for the active OChem coach guide.

## What to do with this directory

- **Don't develop new features here.** Any new OChem work goes into `../ochem/` (v1).
- **Don't link to this from coaching docs.** All hub-level docs (ACELABS_COACH_GUIDE, ACELABS_RECOMMENDED_STACK) point at v1.
- **Don't delete it.** The visualizers, content models, and SVG work in this directory may still be useful as reference or for selective porting back to v1.

## If a coach finds this directory by accident

Read this file. Then close it and open `../ochem/index.html` instead.
