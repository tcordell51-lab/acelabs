# Coach voice clips for OChem, Retold

Drop an audio file here and a "PLAY COACH" control appears on that scene
automatically - no code change needed.

## Naming convention
`n<NIGHT>-s<SCENE>.mp3`  (or `.m4a`)

- NIGHT = the night number (1-13)
- SCENE = the scene number as shown in the tool ("Scene 8" -> s8)

Example: `n5-s2.mp3` is the clip for Night 5, Scene 2 (Markovnikov).

## What the clip should say
Speak to the STUDENT (like the on-screen "walk" text), ~15-30 seconds, in
Thomas's voice. Keep it to the single idea of that scene.

## Formats
mp3 or m4a (AAC). The player tries mp3 first, then m4a.
