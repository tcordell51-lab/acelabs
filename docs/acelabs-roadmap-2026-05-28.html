07Cross-cutting rules to honor

Items that aren't tasks themselves but constrain every task above.

  • No emojis, no decorative unicode glyphs anywhere I write. Including ✓/✗/⚠/★. Use text labels + existing red/green/gold palette.
  • No payment language in student-visible content. No $, paid, balance, package, installment, etc. in any student-facing field, page, or message.
  • No localStorage-only student input. P0 data rule: all student-written content must persist to Airtable (Thomas-visible); localStorage is cache only, never canonical. Applies to any new student-input feature in Phase 2+ (e.g., notes, custom drills, log entries).
  • No score predictors in Ace Labs. No predicted DAT scores, percentile forecasts, or outcome-prediction anywhere. Practice metrics are fine; scaled-score projections are banned.
  • OChem v1 is canonical — augment in place, no parallel v2/v3.
  • Safe-extension architectural rules when touching the portal: provider is frozen, build additively with pure selectors + presentational components + new routes.
  • Thomas Method — FL-driven prep. Skip proactive content review; let PT misses drive every drill. Don't author content "just because" — author against PT-miss patterns.
