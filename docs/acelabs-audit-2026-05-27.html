00The bottom line

Ace Labs is four genuinely substantial, working science engines wrapped in a Prometric-style mock runner and a test-week support layer. The thing demanding attention is not the features — it's that the codebase is mid-pivot and almost none of it is saved.

One sentence

The whole working tree is an in-flight repositioning — from "DAT simulator that predicts your score" to "honest supplemental repair lab" — and that pass is largely built but uncommitted, and the truthfulness cleanup it depends on is only half-integrated, so the live hub still makes claims the new system was written to forbid.

What's genuinely strong
  • Four deep, hand-built engines with real interactives, banks, and spaced-retrieval — the substance is there.
  • The score-predictor removal pass is complete and consistent across all four engines and the dashboard.
  • The Prometric 3-test runner is a real, complete cross-section pacing engine.
  • The new scope / evidence page and its data module are well-built artifacts.
What's fragile right now
  • Nothing in the working tree is committed. One disk loss erases all of it.
  • The scope cleanup is unfinished: validator fails with 17 errors, isn't wired in, and pages weren't retrofitted.
  • The hub still advertises "5 fixed tests" (there are 3) — a live truthfulness regression.
  • A few real per-engine bugs: OChem progress mis-tracking, Bio in-node card gaps.

P0

Untracked files that deployed pages depend on. Deploy risk

Three files are referenced by the app but exist in no commit. Manual CLI deploys from . will ship them, but a fresh git clone or any git-based rebuild would not have them, breaking the pages that link to them:

Fix: Track these in the same commit as the code that references them, so the link and the target always land together.

P1

The hub still says "5 fixed tests" — there are 3. Truthfulness regression

ace-labs.html's Prometric CTA reads "5 fixed tests · 140 Q · 135 min." The catalog, the scope page, and the actual bank (shared/dat-mock-tests.js) all have 3. The hub also still carries "calibrated mocks," and prometric-mock.html says "full simulation" / "mirrors the actual." These are precisely the phrases the new scope validator was written to forbid — the live site currently contradicts the repositioning in flight.

Fix: Correct the hub to "3 fixed tests"; remove "calibrated"/"full simulation"/"mirrors the actual." Ideally drive the number from ACE_SCOPE.MOCKS.count so it can't drift again.

P1

The scope cleanup is half-integrated and its validator fails today. Finish the pass

The scope registry, the public page, and the validator are all built — but the integration is not done. node scripts/validate-scope.js exits 1 with 17 errors: the user-facing pages were never retrofitted with the alScopeStrip / alDisclaimer / shared/scope.js hooks, they still contain stale phrases, validate:scope was never added to package.json, and the validator's own negation allowlist (NEGATION_PATTERNS in shared/scope.js) is defined but never consulted — so it also false-fails correctly-written disclaimers like "not a predicted DAT score."

Fix: Wire the scope hooks into ace-labs.html, prometric-mock.html, mocks-catalog.html; de-stale the copy; make the validator apply NEGATION_PATTERNS before flagging; add "validate:scope" to package.json. Then the validator becomes a real guard against backsliding.

P2

OChem progress tracking is silently broken on its most important hub. Functional bug

The alkene MCQ set uses data-hub="alkene" (singular, tools/ochem/index.html:11323), but the sidebar reader and the Mastery Dashboard both expect "alkenes" (plural, lines 4543 / 21275). Completing alkene questions never lights up the dot or the tile — and alkenes is described in-app as "the center of the universe." Separately, the Mastery Dashboard only counts 10 of 18 hubs (the 8 foundation/advanced hubs and the spec banks are excluded), so the completion ring systematically understates coverage. Three different hub lists in the file disagree with each other.

Fix: Normalize to one hub-id list (alkenes), reconcile the dashboard array and EXISTING_HUBS bars against the 18-hub HUBS source of truth.

P2

Bio: in-node misses don't generate cards for ~23 high-traffic nodes. Content gap

The legacy NODES retrieval entries in tools/bio/bio-shared.js:60+ are placeholder stubs (q:"(question)" …) for 23 nodes — most of Cell and early Genetics. (Misses via the diagnostic and mock still create cards — those build from their own answer text.) Also, the Restart handler hardcodes a stale 28-node list and says "all 20 nodes," so a restart doesn't clear several nodes.

Fix: Author real q/qh/ex for the 23 stub nodes (this is the main outstanding content debt), and rebuild the Restart list from BIO_REGISTRY rather than hardcoding.

05What this tool should be best used as

All four agents converged on the same answer, and it matches the product's own honest copy.

The role

A supplemental, science-section repair lab and pacing rehearsal — used alongside a primary resource (Bootcamp / Booster / Anki), and ideally inside a tutoring session. It is deliberately not a primary course, not a full DAT (no PAT, no RC yet), and — correctly — not a score predictor.

Lean into this

  • Repair specific misconceptions through hand-built interactives — the strongest asset, especially Bio Cell/Genetics/Physiology and OChem mechanisms.
  • Diagnose where to start — the per-engine diagnostics route every miss to a repair node and a spaced-retrieval deck, framed as signal, not a grade.
  • Train recognition and pacing — QR's Pattern Library and Calculator Tax, and the Prometric runner as a covered-section pacing rehearsal.
  • Tutor-in-the-loop — Sarah-mode notes and coach edit-mode make it a live-session companion, which is the real moat.

Don't oversell it as

  • A question-volume grinder — it concedes it can't beat Bootcamp/Booster on count; in-node Bio retrieval is incomplete.
  • A full DAT simulation — PAT is out of scope, RC is only researched, and the mocks cover 2 sections, not the whole exam.
  • "The trick" content engine — yet — until the 94 GC + 34 QR coach cards are authored, that layer is honest placeholder.
  • A score forecaster — by design. That language is being actively removed; the hub's stale claims are the cleanup still to finish.
