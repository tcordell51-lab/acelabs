# Ace Labs · Recommended DAT Prep Stack

The full DAT has six sections. Ace Labs covers four of them — QR, Bio, GC, OChem (the science sections). For PAT and RC you'll need separate resources. This doc gives the honest stack for each section, plus how to budget across them.

The recommendations are pedagogical, not commercial. Pick what fits your student's budget and goal — but don't pretend a single resource is enough when it isn't.

## DAT structure (refresher)

| Section | Time | Questions | Focus |
|---|---|---|---|
| **Survey of Natural Sciences** | 90 min | 100 | Bio (40) · Gen Chem (30) · OChem (30) |
| **Perceptual Ability (PAT)** | 60 min | 90 | Spatial reasoning (not science) |
| **Reading Comprehension (RC)** | 60 min | 50 | 3 passages with timed comprehension |
| **Quantitative Reasoning (QR)** | 45 min | 40 | Math + applied problem-solving |

Total time: ~5.5 hours. Total questions: 280. Each section is scored 1–30 (academic average is the mean of all four subscores excluding PAT).

## What "fantastic" means

DAT scores reference (approximate, varies by year):

| Score | Percentile | Common label |
|---|---|---|
| 17 | ~15th | Low |
| 19 | ~40th | Average |
| 21 | ~70th | Solid |
| 22 | ~85th | Strong |
| 23 | ~93rd | Very strong |
| 24 | ~97th | Excellent |
| 25+ | 99th | Top tier |

Most dental schools accept students with academic average around 19–20. Competitive programs want 21+. Top programs want 22+.

## Per-section honest stacking

### Quantitative Reasoning (QR)

- **Foundation + pattern + anxiety layer:** Ace Labs QR tool with a coach plan ([guides](../AceDAT-QR-Remediation/COACH_GUIDE_README.md))
- **Problem volume layer:** DATBooster OR Bootcamp.com (pick one — they overlap)
- **Calibration layer:** ADA official practice tests (3+)
- **Foundation supplement (if floor):** Khan Academy

For complete QR-specific stacking by starting score, see [QR RECOMMENDED_STACK.md](../AceDAT-QR-Remediation/RECOMMENDED_STACK.md).

### Biology

- **Pattern + visual layer:** Ace Labs Bio engine (Riya · 6 hubs)
- **Memorization volume:** DATBooster OR Bootcamp.com (Bio is largely memorization — volume matters here more than other subjects)
- **Calibration layer:** ADA official practice tests
- **Foundation supplement:** A college-level Bio textbook (Campbell or similar) for any specific gap students surface in diagnostic

Bio is the highest-volume science subject. Students often need 200+ hours total of Bio prep. The Ace Labs Bio engine is excellent for the highest-yield topics; commercial subscriptions add the volume.

### Gen Chem (GC)

- **Pattern + visual layer:** Ace Labs GC engine (Tommy · 37 modules · 605 problems)
- **Problem volume layer:** DATBooster OR Bootcamp.com
- **Calibration layer:** ADA official practice tests
- **Foundation supplement:** A college-level Gen Chem textbook (Atkins or Zumdahl) if the student has been out of school for 2+ years

The Ace Labs GC engine is comprehensive. For most students, GC + a commercial subscription + ADA tests is the full stack.

### Organic Chem (OChem)

- **Reaction maps + animations:** Ace Labs OChem (Tommy · 12 hubs + 10 labs · 27 animations)
- **Problem volume layer:** DATBooster OR Bootcamp.com (OChem-specific question banks are essential — DAT OChem traps are very pattern-specific)
- **Calibration layer:** ADA official practice tests
- **Foundation supplement:** Klein OChem textbook for any specific reaction families a student is shaky on

OChem on the DAT is reaction-recognition-heavy. The Ace Labs reaction maps train this directly. Commercial banks add the variety needed for unfamiliar substrates.

### PAT and RC (not covered by Ace Labs)

Ace Labs does not cover PAT or RC. For these:

- **PAT:** DATBooster or Bootcamp's PAT generator (essential — PAT requires daily practice for 6+ weeks)
- **RC:** DATBooster or Bootcamp's RC drills + read scientific articles daily for 4+ weeks before test

If you want a unified prep stack covering all 6 sections, you'll need a commercial subscription (DATBooster or Bootcamp) on top of Ace Labs regardless of starting score. The commercial subscription handles PAT and RC; Ace Labs handles the four sciences with depth.

## The four resource categories

Every comprehensive DAT prep stack draws from these four categories:

### 1. Ace Labs (this system)

- Anxiety-aware, tutor-driven, pattern-first
- Best for: foundation rebuild · math anxiety · 1:1 coaching · students who want to *understand* the patterns rather than just drill them
- Limitation: doesn't replace problem volume or PAT/RC

### 2. Comprehensive commercial subscription

Pick **ONE** (don't double up — they overlap):

- **DATBooster** (datbooster.com) — big bank, video lessons, multiple full mocks, strong reputation
- **Bootcamp.com** (datbootcamp.com) — comparable bank and lessons, clean cheat sheets, polished UX

Best for: problem volume across all sections including PAT and RC
Limitation: not anxiety-aware; assumes student is already calm and confident

### 3. ADA official practice tests

**Non-negotiable for any student aiming above 20 in any subject.**

The American Dental Association publishes 3–4 official practice tests per cycle. These are the only resources guaranteed to match the real DAT's question style, distractor patterns, and difficulty calibration.

A student who scores 22 on commercial mocks and 19 on the ADA tests is going to walk into the real DAT and score 19 — not 22. **Trust the official material as your truth source.**

### 4. Foundation supplements (free)

- **Khan Academy** — foundational arithmetic, algebra, biology, gen chem
- **Crash Course (YouTube)** — Bio + Chem video lectures for conceptual review
- **YouTube channels** for specific topics where the student has a known gap

Use for: filling specific upstream gaps the diagnostic surfaces. Not a primary resource — a supplement.

## Stack recommendations by goal

### Goal: 18–19 (admission-floor)

- Ace Labs (priority subjects only — the ones the diagnostic flags red)
- ADA official practice tests
- Khan Academy for any pre-foundation gaps
- Optional: commercial subscription if budget allows, but not required

### Goal: 20–21 (median competitive)

- Ace Labs (across all four sciences)
- ONE commercial subscription (DATBooster or Bootcamp)
- All ADA official practice tests
- 4–6 timed mocks total

### Goal: 22–23 (strong competitive)

- Ace Labs with coach plans on all four sciences
- ONE commercial subscription (essential, not optional)
- ALL ADA official practice tests
- 8–10 timed mocks total
- Disciplined daily practice across sciences

### Goal: 24+ (top-tier)

- Ace Labs (mostly for specific weaknesses surfaced by mocks)
- ONE commercial subscription (essential)
- ALL ADA official practice tests
- 10+ timed mocks under real test conditions
- A specific OChem second resource if OChem is the limiting subject (it often is)

At this tier, the limiting factor is rarely content — it's mock execution under stress. Practice mocks in real test conditions: same time of day, same chair, no breaks except scheduled ones, no distractions. Build the test-day muscle, not just the content muscle.

## When the student can only afford ONE thing

Real students have real budget constraints. If they can only pick one:

| Priority | Resource | Why |
|---|---|---|
| 1st | **ADA official practice tests** | Non-negotiable for serious prep. The only material that calibrates real-DAT performance. Cheaper than commercial subscriptions. |
| 2nd | **One commercial subscription** (DATBooster or Bootcamp) | Covers all 6 sections including PAT and RC. Fills the volume layer Ace Labs doesn't aim to provide. |
| 3rd | **Ace Labs + 1:1 coaching** (in 1–2 priority subjects) | The tutor-led pattern + foundation work that fills the biggest single gap most students have. Worth more than another commercial subscription. |

If the student can only afford the commercial subscription and skips coaching: they'll get to 19–20 with discipline. They won't get to 22+ in math-anxious or foundation-shaky subjects without addressing the pattern + trap awareness layer that Ace Labs (or 1:1 coaching) provides.

## Time budgeting across sections

Realistic time budget for a student aiming 21+ across all sections, over 12 weeks:

| Section | Hours/week | Total over 12 weeks |
|---|---|---|
| Bio | 6–8 | 80–95 |
| Gen Chem | 4–6 | 50–70 |
| OChem | 4–6 | 50–70 |
| QR | 4–5 | 50–60 |
| PAT | 4–5 (last 6–8 weeks) | 25–40 |
| RC | 2–3 (last 4–6 weeks) | 8–18 |
| Mocks + review | 4–6 (last 6 weeks) | 24–36 |

Total: roughly **300–400 hours** of prep over 12 weeks. The students who fall below that range usually score below their potential.

## When to start each subject

Order matters. A typical 12-week plan:

| Week | Bio | GC | OChem | QR | PAT | RC |
|---|---|---|---|---|---|---|
| 1–2 | Start | | | Start | | |
| 3–4 | | Start | | | Start | |
| 5–6 | | | Start | | | |
| 7–8 | All 4 sciences active · QR pattern phase · PAT daily · 1st mock | | | | | |
| 9–10 | All active · 1st ADA test · 2nd mock | | | | | Start |
| 11 | All active · 2nd ADA test · 3rd mock | | | | | |
| 12 | Light review · 3rd ADA test · final mock · rest before test | | | | | |

QR typically goes first because the foundation rebuild has to happen before timed practice can build speed. Bio joins early because volume is the biggest factor. OChem and GC overlap and start in week 3–6. PAT requires daily practice for 6+ weeks before test. RC requires 4+ weeks of daily reading.
